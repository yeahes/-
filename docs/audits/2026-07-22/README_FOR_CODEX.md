## 工作边界

第一轮只做低风险基础设施和确定性修复。

### 允许修改

- 中间产物保存
- 验证器与质量门禁
- 固定回归测试入口
- 相邻中文字幕重复检测
- 中文阅读速度检测
- 连续有声但无字幕检测
- ASR可疑片段标记
- 局部修复入口和报告

### 暂不修改

- 不引入动态规划切分器
- 不大拆 `screen_editor.py`
- 不整体替换 ASR 后端
- 不改变现有稳定模式正常路径的输出
- 不针对 000/222/888 的具体文字添加硬编码特例
- 不让中文阶段修改英文文本、英文字幕 ID 或时间轴

## 必须遵守的架构规则

1. 词级时间戳是需要验证的测量值，不是绝对真值。
2. 词级账本可以保证引用、覆盖和顺序，但不能证明时间准确。
3. 英文切分完成并验证后，冻结英文、字幕 ID 和时间轴。
4. 中文阶段只允许写入中文字段。
5. 中文第二阶段只能分配或有限压缩第一阶段完整译文，不得重新翻译英文。
6. ERROR 不得进入最终合成。
7. 自动修复只处理局部问题；修复后必须重新验证。
8. 不得为了单一测试样本加入文本特例。

## 首轮任务

### A. 建立固定回归入口

增加一个无需视频合成即可运行的测试命令，例如：

```bash
python -m tests.caption_audit.run_all
```

输出：

- 每个样本的指标
- 与基线的变化
- ERROR / WARNING 数量
- 失败字幕 ID
- 机器可读 JSON 报告
- 人类可读 Markdown 报告

### B. 建立三类确定性检测

1. 连续有声但无字幕
   - 字幕间存在异常空档
   - 空档内 VAD 显示明显人声活动
   - 000 第18条附近必须被检出

2. 阅读速度
   - 英文词/秒
   - 中文汉字/秒
   - 中文目标 6–8 字/秒
   - >9 字/秒 WARNING
   - >11 字/秒 ERROR
   - 阈值必须配置化

3. 中文重复
   - 相邻字幕完全重复
   - 高相似度重复
   - 同一语义组内异常复述
   - 888 第12–13、69–70、109–110附近必须被检出

### C. 建立 ASR 可疑文本标记

先只报告，不自动改英文。

触发信号包括：

- 英文局部语法明显不成立
- 同一实体出现多种近似拼写
- 疑似缺少否定词、冠词或关键单词
- 上下文语义自相矛盾

报告应包含：

- 字幕 ID
- 时间窗口
- 可疑英文
- 触发原因
- 建议局部重转录的音频区间

### D. 验证器分级

ERROR：

- 英文覆盖缺失、重复、错序
- 时间倒序或非法重叠
- 连续有声但无字幕超过阈值
- 中文字幕为空
- 中文字幕严重超速
- 字幕 ID 不一致

WARNING：

- 疑似坏切点
- 轻度阅读速度超限
- 相邻中文重复
- 疑似翻译腔
- 疑似 ASR 错误
- 独立口头语

## 验收要求

1. 现有稳定模式在正常样本上不得产生英文漏词、重复或错序。
2. 000 的有声空档必须被检测。
3. 888 的明显中文重复必须被检测。
4. 222 的末段中文破句至少应被标为 WARNING。
5. 自动检测必须输出具体字幕 ID，不得只给总数。
6. 不得因为 WARNING 阻断全部合成。
7. ERROR 应阻断最终合成，但保留全部中间产物。
8. 所有新增阈值均应配置化并有测试。
9. 运行完整回归测试后，提交基线与新结果对比。
10. 在修改代码前，先给出实施计划和预计修改文件；不要先动代码。
