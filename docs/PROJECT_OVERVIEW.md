# Project Overview

## Goal

This project is a working copy of VideoCaptioner focused on producing English-learning video podcast episodes from NotebookLM-generated English audio.

The desired output is:

- Stable English subtitles on top.
- Natural Simplified Chinese subtitles below.
- Static educational video rendering with the podcast learning template.
- Predictable timing, minimal blank subtitle gaps, and no missing spoken English.

## Inputs

- English podcast audio, usually generated by NotebookLM.
- Optional static background image for video synthesis.
- Local ASR output from FasterWhisper, Qwen3-ASR, or related timestamp tools.
- LLM service for Chinese translation only.

## Outputs

- Bilingual SRT files.
- Styled ASS subtitles.
- `stable-final-*.srt` files for deterministic video synthesis.
- `stable-final-manifest.json` pointing synthesis to the final stable subtitle.
- Validation and audit reports.
- Final rendered educational video.

## User Quality Priorities

1. No missing English while audio is speaking.
2. English subtitles should normally contain 6-12 words and must stay within 16 words, except for audited 17-19 word grammar-preserving cases.
3. English text must match the audio and must not be rewritten.
4. Chinese should read like concise magazine/documentary narration.
5. Subtitle timing should not disappear before the audio finishes.
6. Video synthesis must use the latest stable subtitle output, not stale files.

## Mature Enough To Preserve

- The E-drive working copy.
- Stable mode direction: local English segmentation plus LLM Chinese translation.
- Podcast learning video template path.
- `stable-final-manifest.json` based subtitle resolution.
- Regression tests under `tests/`.

## High-Risk Areas

- `screen_editor.py` is highly coupled and has accumulated many subtitle rules.
- LLM candidate quality check can change English and timing indirectly.
- Old generated SRT/ASS files can be accidentally reused by synthesis.
- Word-level timestamps from ASR/stable-ts can be too short or have gaps.
