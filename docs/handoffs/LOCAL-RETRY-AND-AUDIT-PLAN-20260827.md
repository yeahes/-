# 阻断后的局部重试与翻译审计计划

时间：2026-08-27 13:48:43 +08:00

## 目标

后续遇到可定位的下游阻断时，只重试失败的父句、页面或翻译批次；已经
通过的结果保持冻结。局部重试仍失败时，继续对已经冻结且资料完整的父级
英文/中文运行只读翻译质量审计，最后把剩余失败项交给人工终稿编辑器处理。

## 不变的安全边界

- 不重跑 ASR、faster-whisper、英文切分、字幕 ID、词账本或最终时间轴。
- 不让审计结果改写英文、中文、字幕 ID、页面顺序或时间。
- 页面失败可以继续审计，但 `render_blocked` 仍为真；审计通过不等于允许出片。
- 英文来源、固定 ID、词账本或父级中文不完整时，继续失败关闭，不伪造审计依据。

## 错误分层

| 错误 | 局部范围 | 重试失败后 | 是否继续父级审计 |
| --- | --- | --- | --- |
| 分页中文缺失、重复、错页、源回显不一致 | 失败父句的完整页面集合 | 保留成功父句，失败父句进入人工清单 | 可以，前提是父级英文/中文/ID 完整 |
| 分页语义或通顺度校验失败 | 对应父句 | 保留原始合法页，记录 REVIEW/ERROR | 可以 |
| 父级翻译/固定 ID allocation 单组失败 | 失败语义组或固定 ID | 缺失 ID 继续阻断发布 | 只能审计完整 ID 行 |
| 翻译质量审计请求/解析失败 | 批次 -> 更小批次 -> 单条 | 审计标记 `PARTIAL`，不改字幕 | 其余批次继续 |
| ASR 漏词、英文冻结失败、ID/词账本/最终时间轴损坏 | 无安全局部范围 | 硬阻断 | 不把不可信数据当正常审计源 |

## 实施顺序

1. 统一错误证据字段：`stage`、`retryable`、`scope_type`、`scope_ids`、
   `attempts`、`remaining_ids`。没有明确 scope 的错误不得局部化。
2. 复用现有页面重试入口，让 `S0136`、`S0260` 只生成各自父句的请求；合并
   时只替换该父句，其他已通过页面保持原缓存和原内容。
3. 页面阶段失败后，只要冻结父级资料完整，就调用
   `_run_translation_quality_audit(..., allow_page_projection_failure=True)`；
   页面错误仍单独写入阻断清单。
4. 人工终稿编辑器只展示 `remaining_ids` 对应的页面，人工修复后重新做页面
   ID、中文串接、源回显和渲染校验，不重新跑上游阶段。
5. 为第 1 项补假响应测试：成功父句不重复请求、失败父句局部降级重试、重试
   仍失败时审计仍被调用、审计结果只写报告、最终渲染仍保持阻断。
